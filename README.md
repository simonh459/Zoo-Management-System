# Zoo-Management-System

Used by a zookeeper, the zoo management system allows them to add, remove, and edit an animal. Includes a zoo report which updates in real-time when data is entered into the system. 

The program shows off my practical skills learnt from the module, demonstrating my knowledge on the four core principles of Objected Orientated Programming.

Unit Testing provided showing my ability to validate and ensure my code works as intended.
